本版更新（v1.15.0）

  • 新增：播放失败自动使用本地缓存兜底——在线获取地址失败时自动播放本地已下载的同一首歌（可关闭）
  • 新增：播放详情页显示当前实际播放音质徽标（如 320K · KW）
  • 新增：播放页屏幕常亮开关（设置 → 播放）
  • 新增：自定义背景不透明度与模糊度调节（设置 → 主题）
  • 新增：WebDAV 自动备份频率（每次启动 / 每天一次 / 每周一次）
  • 新增：关于页「引用项目 / 致谢」与「赞赏支持」入口
  • 以上功能移植自 LX-X Music（WalnutBai/lx-lxwalnut-music-mobile），致谢见关于页

源码 / 自建一起听

基于 lyswhut/lx-music-mobile 修改；部分功能移植自 LX-X Music，详见关于页引用项目。源码已托管 GitHub：

  • App 源码：yzdz666/lx-music-mobile-mod
  • 服务端 / 网页版源码：yzdz666/listen-together-server
下载二改源码（打包版）含 listen-together-server 与正式签名密钥，可自己部署和编译
  • 自建房间服务器：cd listen-together-server && npm install && node index.js
  • App 设置 → 其他 → 一起听服务器地址，填 ws://你的服务器:23333
  • 网页版直接访问 http://你的服务器:23333/
  • 详细说明见源码包 listen-together-server/README.md
